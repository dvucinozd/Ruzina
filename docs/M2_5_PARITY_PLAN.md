# M2.5 parity audit and Rust development plan

Reviewed: 2026-10-22. Status: **planning baseline; implementation gaps remain open**.
Targets remain Guition JC1060P470C_I_W_Y and JC8012P4A1C_I_W_Y, silicon v3.2.

## Scope and pinned references

The review compares donor history, changed product modules, controller tooling,
tests, release/qualification records, current master and retained contributor
branches against the current Rust crates, simulator and requirements. It does
not treat every donor file or passing donor test as Rust parity evidence.

| RP-08 P0: duration and cold MP3 seeks | **Host-implemented 2026-10-22; firmware wiring compile-only.** `mp3_index` walks Layer III frame headers without decoding, after ID3v2. It also detects Xing/Info/VBRI and bitrate changes. A cold seek farther than one stride from every checkpoint resumes through the codec's own reservoir preroll. Constant streams (complete walk, one bitrate) use its exact byte arithmetic. Xing/VBRI streams are asked to resume at an indexed frame and are fed from that frame's walked offset instead of the ~1 % table of contents; the gapless lead is learned from the codec, and any inconsistency falls back.
