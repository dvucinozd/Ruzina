# JC1060: the Web Remote names its deck

Date: 2026-11-16. Branch: `ogranak/jc1060-deck-name`, from `main` at `9f59211`
(after [four connections at once](2026-11-16-web-connections.md)).

## Change

**The page now shows which deck it drives**, which matters once there is more than one.
The name is the deck's network name, `Ruzina-AB2D` on this board.

- **`ruzina-web`** (the shared crate):
  - `StatusParts` and `StatusSnapshot` carry a `name`.
  - `/api/status` writes it after the stamp as `"name"`.
  - The page shows it in its header, in place of "Web Remote", and in the browser tab's
    title.
  - The desktop simulator reports "Ruzina Simulator".
- **JC1060:**
  - Once the access point is up, `main/wifi_remote.c` hands its name to the Rust core
    (`ruzina_web_set_name`).
  - The web task keeps it in `WebState` and puts it in the status.
